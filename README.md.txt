# ⛅ Weather App Pro

A clean and interactive real-time weather forecasting application that fetches live weather data.

![Weather App Background](https://weather-app-pro-one.vercel.app/weather-preview.jpg)

**🚀 Live Demo:** [weather-app-pro-one.vercel.app](https://weather-app-pro-one.vercel.app/)

**🛠️ Tech Stack**
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Deployment:** Vercel

**✨ Key Features**
* Real-time weather search by city name.
* Displays accurate temperature, humidity, and weather conditions.
* Clean folder structure (CSS and JS separated).

**💻 Local Setup**
1. Clone the repository: `git clone https://github.com/pushpender1043/weather-forecasting-app.git`
2. Open `index.html` in any web browser.
